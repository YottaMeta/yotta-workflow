# 元序复杂场景走查

## 走查 1：项目开工

1. 读取当前目录，判定项目根。
2. 读取 STATE / TASKS / ROADMAP / DECISIONS。
3. 汇总当前进度与下一步。
4. 执行前先确认本次会话目标与验收。

## 走查 2：任务中主动落盘

背景：一个功能已改完一半，后续还有测试和文档。

1. 立刻更新 STATE 当前进度。
2. 在 TASKS 勾选已完成项。
3. 如有新决策，写入 DECISIONS。
4. 当天日志追加一条简短记录。
5. 继续执行剩余步骤。

## 走查 3：收工锚点

1. 更新 STATE / TASKS / ROADMAP。
2. 追加当天日志。
3. 输出固定格式锚点，包含项目、路径、时间、进度、已完成、下一步、关键决定、遗留问题、开工读取路径。
4. 确认锚点与状态文件一致。
