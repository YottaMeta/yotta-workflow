# 元序异常恢复手册

## 1. 状态文件缺失

- 信号：项目存在但状态目录不存在。
- 动作：按项目根初始化标准结构，不覆盖既有机制。
- 恢复：读取项目文档与用户补充信息，重建最小状态。

## 2. 并发写入冲突

- 信号：两个会话同时更新同一状态文件。
- 动作：停止整文件重写，改为读取后合并。
- 恢复：保留双方有效信息，冲突处标注来源并请用户确认。

## 3. 状态文件过大

- 信号：单文件明显超过常规阅读量。
- 动作：拆分历史内容，保留当前快照。
- 恢复：STATE 只留当前进度，历史写入日志或专项文档。

## 4. 既有机制冲突

- 信号：项目已有自己的交接文件。
- 动作：沿用原机制，只补足开工读取与收工锚点。
- 恢复：把本协议必要字段映射到原机制，不重复建一套状态。

## 5. 会话中断

- 信号：用户直接开新会话，未走收工流程。
- 动作：先读状态，再请用户补充缺失点。
- 恢复：确认后从下一步继续，不假装记得对话内容。
